# One Word From Grandma

Entry for the make.fun competition
`u-0xkianno-one-word-from-grandma-f04bed16`.

The program writes exactly one word — the single word Grandma would text
about AI — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when
that variable is set). The word is fixed, so every run produces the same
bytes.

Run: `python3 main.py`
